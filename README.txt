SRI BINAYAK PRAGATI YUVAMANCHA — starter website

Files:
- index.html: responsive, mobile-friendly bilingual English/Odia website.

Important before publishing:
1. Replace/add the organization's approved public phone number and email in the Contact section.
2. Add actual event dates and photos only after they are confirmed.
3. Create Google Forms for membership and blood donor interest, set access carefully, and link them only after testing.
4. Do not publish donor names, phone numbers, blood groups, addresses, or other personal details.
5. Do not enable online donations until the organization has an appropriate bank/payment arrangement and required approvals.
6. This is a static starter website. It does not store or submit form data and has no admin dashboard yet.

Free publishing option:
- GitHub Pages: create a public repository, upload index.html, then enable Pages from repository Settings.
- Cloudflare Pages: connect a GitHub repository and deploy the static site.
- The free hosting address is a provider subdomain; a custom domain generally costs money.

The website currently uses only HTML/CSS/JavaScript and needs no paid theme or plugin.
